# Roadmap: от набора конфигурации к полноценному агенту

Обновлено 2026-10-03. Этапы 0–7 реализованы в рабочем дереве ветки `feat/aqa-agent`
(не закоммичено). Открытые пункты собраны в разделе «Что осталось».

Обозначения: `[x]` — сделано и проверено локально; `[~]` — сделано, но не проверено в
реальном окружении; `[ ]` — не сделано.

## Этап 0. Починить то, что было сломано

- [x] **Установка затирала файлы целевого проекта.** Правила агента вынесены из `AGENTS.md`
      в скилл `aqa-workflow`. `AGENTS.md` и `CLAUDE.md` теперь описывают только разработку
      этого репозитория и в целевой проект не копируются.
- [x] **Скиллы не были подключены к сабагенту.** Убрано ограничение `tools` (агент наследует
      `Skill` и MCP), добавлено `skills: [aqa-workflow]`. Проверено headless-запуском: агент
      `aqa:aqa` видит все 12 скиллов и MCP-сервер Playwright.
      Оговорка: предзагрузка через `skills:` в режиме `--agent` не сработала — в контексте
      оказалось только описание скилла. Поэтому персона явно требует загрузить
      `aqa-workflow` первым шагом; в evals скилл вызывается.
- [x] **Запуск из README не существовал.** README переписан: установка плагином или
      `scripts/install.sh`, ссылки на `make dc-claude` и `py-devops-agent` убраны.
- [x] **Шаг верификации противоречил границам.** В `aqa-workflow` описан механизм
      («Proving a test can fail»): мутация в одноразовом git worktree, откат через
      `git checkout` при чистом дереве, мутация на сетевой границе для удалённого продукта,
      отдельное правило для регрессионного теста по баг-репорту.
- [x] **Висячие ссылки на скиллы.** Довезены `unit-testing` и `test-reliability` (тот же
      upstream-коммит `b3bb61b`). Остальные имена оставлены в тексте чужих скиллов, чтобы не
      расходиться с upstream: `aqa-workflow` велит агенту считать такую ссылку темой вне
      комплекта, а `tests/test_repo.py` хранит список известных отсутствующих имён.
- [x] **Устаревшие модели и заглушки.** В `ai-test-generation` имена моделей заменены на
      описание уровней. Из Codex-персоны убран `model` — используется модель из профиля
      пользователя. Секция Commands в `AGENTS.md` заполнена реальными командами.

      проверяется `aqa_lint.py trace` в обе стороны.

## Этап 6. Evals и CI

- [x] `tests/`: 99 тестов — линтер и согласованность репозитория (frontmatter скиллов,
      файлы `references/`, ссылки Related, персоны, манифест, README). `ruff` и `mypy
      --strict` чистые. `pyproject.toml` исправлен: `uv sync` раньше падал бы на сборке
      несуществующего пакета.
- [x] 4 eval-кейса для `claude plugin eval` на фикстуре `evals/_shop/`. Все проходят
      (по 1–2 прогона на кейс, суммарно около $2.7):
  - `cases-stop-at-gate` — артефакты на диске, матрица `draft`, тестов нет, просит ревью;
  - `generate-blocked-by-draft` — при `draft` тесты не пишет и статус сам не меняет;
  - `generate-from-approved` — тесты со ссылками на все `SC-NNN`, продукт не тронут;
  - `bug-report-keeps-product` — регрессионный тест, баг описан, продукт не исправлен.

  Первый прогон последнего кейса выявил, что при снятом гейте агент пропускал матрицу;
  правило в `aqa-workflow` ужесточено, после этого 2 из 2.
- [~] `.github/workflows/ci.yml`: линт, типы, тесты, проверка персон и манифестов; evals —
      опционально (`RUN_EVALS=true` и секрет `ANTHROPIC_API_KEY`). В GitHub Actions не

1. **Закоммитить и запушить**, после чего проверить установку из marketplace и CI.
2. **Прогон на `issuer-agent`**: нужен конкретный тикет или фича. Это первая проверка на

   покрыты, потому что в песочнице фикстуры нет pytest.
3. **Трекер задач**: если нужен Jira или Linear — добавить их MCP-сервер в `.mcp.json`.
4. **Проверить в Codex CLI**: пути `.codex/agents/`, формат `aqa.toml`, загрузка скиллов.
5. **Evals с реальным запуском тестов**: фикстура с установленным pytest (или TS-проект с
   Playwright), чтобы оценивать `aqa-verify` целиком, включая мутационную проверку.
6. **Скрипт сверки селекторов и эндпоинтов** с исходниками — сейчас это делает агент.
7. **Windows**: `aqa_lint.py` и `install.sh` на Windows не проверялись.
